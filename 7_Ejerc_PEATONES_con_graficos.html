1.2 Analizar y transformar los tipos de datos¶

Por el trabajo del tema anterior ya sabemos que

  • PEATONES, NÚMERO_DISTRITO, NÚMEROy CÓDIGO_POSTAL son int64,
  • LATITUD y LONGITUD son float64.
  • resto son de tipo object

Pero en python tenemos un tipo de datos específico para la fecha y la hora

1.2.1 Fechas¶

En Python podemos trabajar con distintos tipos de datos temporales:

  • date: representa una fecha: año, mes y día.
  • time: representa una hora: hora, minutos, segundos.
  • datetime: representa fecha y hora conjuntamente

Usamos pd.to_datetime() para convertir los tipos de los valores de la columna FECHA. Además, necesitamos el parámetro dayfirst = True para indicar a pandas que, al interpretar una fecha, el primer número corresponde al día pues la fecha está escrita con el día antes del mes.

Al ejecutar df["FECHA"] = pd.to_datetime(df["FECHA"], dayfirst=True) da error porque el fichero hay dos formatos diferentes en las fechas, unos es con la hora 01/01/2020 00:00 y el otro es sin hora 02/09/2020. Pandas ha inferido inicialmente el formato %d/%m/%Y %H:%M pero ha detectado un valor que no seguía este formato. Pandas nos aconseja que tomemos el formato mixto para la fecha.

df["FECHA"] = pd.to_datetime(
    df["FECHA"],
    dayfirst = True,
    format = "mixed"
)

# comprobamos el tipo del primer valor de la columna `FECHA`
type(df["FECHA"].iloc[0])

pandas._libs.tslibs.timestamps.Timestamp

Ahora sí que estamos trabajando con fechas reales y podemos, por ejemplo, extraer de FECHA una parte concreta utilizando el accesor .dt. Prueba primero con el año (df["FECHA"].dt.year), después con el mes y finalmente con el nombre del día de la semana.

1.2.2 Horas¶

Ahora vamos con la columna HORA que aparece como texto de la forma 00:00 y 01:00. Estos valores podemos convertirlos a un tipo de hora de pandas pero, pandas no tiene una función pd.to_time(). Necesitamos hacer un pd.to_datetime() con formato %H:%M como parámetro. Finalmente, aplicamos pd.to_datetime().dt.time para quedarnos únicamente con la parte de la hora.

df["HORA"] = pd.to_datetime(
    df["HORA"],
    format="%H:%M"
).dt.time

1.6 Calcular el total de peatones por día de la semana¶

Para analizar los peatones por día de la semana, necesitamos añadir una nueva columna con dichos datos. Es decir, a partir de FECHA, crea una nueva columna llamada DIA_SEMANA. El accesor .dt tiene un método day_name() que devuelve el nombre del día de la semana.

df_1["DIA_SEMANA"] = df_1["FECHA"].dt.day_name()

Si queremos los nombres en español, debemos traducir los nombres en inglés que devuelve day_name(). Para ello creamos un diccionario que relaciona cada nombre en inglés con su equivalente en español y aplicamos map(), que realiza la sustitución de forma vectorizada. Es más rápido que recorrer todas las filas con un bucle, especialmente en un conjunto de datos grande.

dias = {
    "Monday": "Lunes",
    "Tuesday": "Martes",
    "Wednesday": "Miércoles",
    "Thursday": "Jueves",
    "Friday": "Viernes",
    "Saturday": "Sábado",
    "Sunday": "Domingo"
}


df_1["DIA_SEMANA"] = df_1["FECHA"].dt.day_name()

for i in range(len(df_1)):
    df_1.loc[i, "DIA_SEMANA"] = dias[df_1.loc[i, "DIA_SEMANA"]]

# Esto tarda

peatones_dia = df_1.groupby("DIA_SEMANA")["PEATONES"].sum().sort_values(ascending=False)

etiquetas_horas = [hora.strftime("%H:%M") for hora in peatones_hora_grafico.index]

plt.figure(figsize=(5, 3))
plt.bar(etiquetas_horas, peatones_hora_grafico.values)
plt.title("Total de peatones registrado por hora del día")
plt.xlabel("Hora")
plt.ylabel("Total registrado")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
